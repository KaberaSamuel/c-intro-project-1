# C Programming Intro: Project 1

This is my project for the C programming intro course. It has four small projects, three C programs that run in the terminal and one Arduino project that I built and simulated in Tinkercad.

## What is inside

- `question-1/` is a water quality monitoring program. It reads a temperature and a turbidity value, calculates a water quality index and prints a report that says if the water is Good, Warning or Critical.
- `question-2/` is a mobile money transaction program. It shows a menu where the user can deposit, withdraw, check the balance and see a summary of the transactions. It rejects invalid things, like withdrawing more than the balance.
- `question-3/` is a delivery route analysis program. It reads the distances of some delivery routes into an array and uses separate functions to get the total, the average, the longest route and how many routes are above a limit. There is also a recursive function that sums the array.
- `question-4/` is a smart parking system. An ultrasonic sensor measures the distance in front of it. If the space is free the green LED turns on, and if the space is taken the red LED turns on and the buzzer sounds.
